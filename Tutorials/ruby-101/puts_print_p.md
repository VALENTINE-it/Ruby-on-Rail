### 1.print
What it does: Prints the text as is, but does not move the cursor to a new line.Newline: No. If you multiply the commands print, all the results will be on one line.Example:ruby

print "Habari "
print "Yako"

### 2. puts(Put String)
What it does: It types text and automatically moves to a new line at the end of the word.Example:ruby

puts "Habari"
puts "Yako"
